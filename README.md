# 🌌 Absolut kein Plan. Nur Stories.

Ein halb reales Tagebuch, halb spekulativer Zettelkasten. **Chaos an der Oberfläche — darunter ein vernetztes Netz aus Motiven, Menschen und Parallelwelten.**

> *Notizen, Beweisfotos, verschwommene Tagebucheinträge, Audio-Samples, Skizzen vom Rand der Wirklichkeit.*

---

## 🎭 Was ist das hier?

**Kein-Plan-Nur-Storys** ist ein experimenteller Life-Blog, der die Grenzen zwischen Dokumentation und Fiktion bewusst verschwimmen lässt. Hier findest du:

- 📝 **Reale Begehungen & Tagebucheinträge** — markiert mit `#Echt`
- 🎨 **Spekulative Essays & Doodles** — gekennzeichnet mit `#Fiktion`
- 🎵 **Audio-Fragmente & Klangcollagen** — 12-Sekunden-Loops aus Berlin
- 📸 **Polaroid-Archive & Fotoserien** — mit Kratzern und Ecken
- 🗺️ **Thematische Kartographien** — Orte, Motive, Personen verbunden

### Die Core-Idee

Eine Plattform für **transparente Hybridform**: Wo echt? Wo fiktiv? Schieberegler statt Sicherheit. Ein **Reality/Fiction-Slider** ermöglicht es Leser:innen, zwischen pure Fiction (0) und dokumentiertem Realismus (100) zu navigieren.

---

## 🚀 Features

### Chaos-Feed
Kartenbasiertes Grid mit Shuffle-Modus — zufällige Entdeckungsreisen durch Stories, Audios, Fotos und Skizzen.

### Story-Fäden & Timelines
Drei parallele Erzählstränge:
- **Realer Strang**: Nachtzug, Archivinstallation, Mixed-Media-Performance
- **Fiktive Linie**: Parallelgesellschaft, fragmentierte Botschaften
- **Zwischenräume**: Tonband, Persona "Lila", ungesicherte Notizen

### Reality/Fiction-Slider
Dynamischer Fokus-Schieberegler:
- **0–30%**: Pure Fiction (Acid Lime Highlights 🟢)
- **30–70%**: Hybrid/Zwischenräume (Cyan Akzente 🔵)
- **70–100%**: Dokumentierter Realismus + Quellenverweise (Warm Red 🔴)

### Themen-Karte (Draggable Nodes)
Interaktive Karte mit Motiven:
- Berlin Echo
- Nocturne
- Polaroid-Archiv
- Fiktive Sphäre
- Persona Lila

### Newsletter & Kontakt
- Signale einschalten: Erhalte Updates, RSS-Feeds, Traumfragmente
- Gastbeiträge & Kollaborationen willkommen
- DM: @fluxnotes

### Archiv & Tags
Filterbare Tags für Navigation:
`#Berlin` `#NocturnalSounds` `#Polaroid` `#Chronik` `#Fiktion` `#Realitätsmonitor` `#Audio` `#Glitch` `#Collage`

## 🛠️ Tech-Stack

### Frontend
- **React** — Komponentenbasierte Architektur
- **Tailwind CSS** — Responsive Styling
- **JavaScript/ES6** — Interaktivität

### Komponenten
```
├── HeroSection           — Landing Hero mit CTA
├── ChaosFeed            — Shuffle-able Feed Grid
├── TimelineSection      — Story-Fäden & Filter
├── RealitySlider        — Reality/Fiction Toggle
├── ThemeMap             — Interaktive Nodes
├── AboutSection         — Über Autorenschaft
├── HighlightsSection    — Rabbit Holes & Easter Eggs
├── NewsletterSection    — Subscribe Form
├── ContactSection       — Kontakt & Collaboration
├── ArchiveSection       — Suche & Tags
└── SiteFooter           — Credits & Info
```

- **Colors**:
  - Hintergrund: `#0F0F10` (Deep Black)

  - Accent: `#00E5FF` (Cyan)

## 📋 Installation & Setup

### Prerequisites
- Node.js 16+
- npm oder yarn

### Installation
```bash
git clone https://github.com/xdndbh5h8d-lab/Kein-Plan-Nur-Storys.git
cd Kein-Plan-Nur-Storys
npm install
```

### Development
```bash
npm run dev
# Öffnet http://localhost:3000
```

### Build
```bash
npm run build
npm start
```

## 📝 Content-Guidelines

### Kennzeichnung
- **Echte Inhalte**: `#Echt` — Fotos, Interviews, Tonaufnahmen
- **Fiktive Inhalte**: `#Fiktion` — Essays, Doodles, anonyme Briefe
- **Hybrid**: `#Hybrid` — Fiktionalisierte Erinnerungen

### Ethik
✅ Transparenz über Autorenschaft  
✅ Hinweis auf Fiktionalisierung  
✅ Respekt für echte Stimmen & Interviews  
✅ Keine Tracking-Bomben — Privacy-konform
